# ATS_resume
Gen AI based ATS resume checker and help identify gaps with respect to jobs


Built a web app using streamlit, it ask for users Resume/Cover letter etc and the job description, it has differnet functionality basis different prompts, which will help user with whatever strengths, weakness and different anlysis according to the job. It uses Chroma DB to store resume and then rerives the information as per the job description and the prompt user inputted to give the anser. Below is how the web app looks like.
